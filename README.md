# jeroengroeneweg.nl

The public portfolio site for Jeroen Groeneweg.

It is a static site designed for GitHub Pages. Changes merged into `main` deploy through the included GitHub Actions workflow.

“The work” opens with the BridgeFund story: building internal product, engineering and data teams, adopting Mambu and HubSpot, and focusing development on credit risk and the customer journey. All five paragraphs follow a single top-to-bottom reading order on desktop and mobile, ending with agentic engineering and the business outcome.

A numbered “Key ingredients for this successful transformation” section follows the story, before the transformation results.
