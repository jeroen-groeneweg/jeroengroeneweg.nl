# jeroengroeneweg.nl

The public portfolio site for Jeroen Groeneweg.

It is a static site designed for GitHub Pages. Changes merged into `main` deploy through the included GitHub Actions workflow.

“The work” opens with the BridgeFund story: building internal product, engineering and data teams, adopting Mambu and HubSpot, and focusing development on credit risk and the customer journey. The story reads down each column on desktop and stacks in the same order on mobile.
