Game development now opens a playable black-and-white Pong canvas. Press Enter while the game is focused (or use Start), use ↑/↓ for the left paddle, and race the computer to five points. Paddle impact changes the ball angle and gradually increases its speed; the computer has bounded speed, reaction delay and aiming error. Touch players can hold the two arrow buttons. Escape, loss of focus, a hidden browser tab or scrolling the canvas out of view pauses play; Enter resumes.
