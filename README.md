# jeroengroeneweg.nl

The public portfolio site for Jeroen Groeneweg.

It is a static site designed for GitHub Pages. Changes merged into `main` deploy through the included GitHub Actions workflow.

“My Work” contains the BridgeFund story organised by year, introduced by a short explanation of its practical lessons and purpose. Year one contains six chapters and a recap; year two contains nine chapters and a recap. Native HTML details and summary elements make every year and chapter expandable with mouse, touch or keyboard, without JavaScript. All years and chapters are collapsed on initial load. Years three and four will be written later.

Each chapter includes the narrative, a lesson and a question for the reader. The year one recap retains the four key ingredients. Keep text in index.html and accordion styling in styles.css. Verify both default open states and keyboard toggling when changing the chapter layout.
